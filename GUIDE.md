# 📖 Quick Start Guide

## Getting Started

### Login
1. Open `index.html` in your browser
2. Enter credentials:
   - **Username**: `admin`
   - **Password**: `1234`
3. Click "Login"

### Adding Tasks
1. Type task description in the input field
2. Select a deadline (optional)
3. Choose priority level (🟢 Low, 🟡 Medium, 🔴 High)
4. Click "+ Add Task" or press **Enter**

### Managing Tasks

| Action | How |
|--------|-----|
| **Complete** | Click the circle (○) button |
| **Edit** | Click the pencil (✏️) button |
| **Delete** | Click the trash (🗑️) button |
| **Search** | Type in the search box |
| **Filter** | Click filter buttons (All, Pending, Completed, High Priority) |

### Features

#### Progress Tracking
- See your completion percentage in the large circle
- Stats cards show: Total, Completed, Pending, High Priority tasks
- Motivational messages update as you progress!

#### Theme Toggle
- Click the moon/sun icon (🌙/🌞) in top-right
- Your choice is saved automatically

#### Logout
- Click the "Logout" button
- Your tasks will be saved for next login

## Tips & Tricks

✨ **Keyboard Shortcuts**
- Press **Enter** after typing to quickly add a task
- Press **Escape** to close the edit modal

🔍 **Search Tips**
- Search as you type - results update instantly
- Search works with all filter types

🎯 **Priority System**
- 🔴 **High**: Urgent tasks
- 🟡 **Medium**: Standard tasks (default)
- 🟢 **Low**: Non-urgent tasks

📱 **Mobile Usage**
- App is fully responsive
- Touch-friendly buttons
- Landscape and portrait modes supported

## Data Storage

All your data is stored locally in your browser:
- ✅ Tasks
- ✅ Login state
- ✅ Theme preference
- ✅ Task order (if dragged)

⚠️ **Important**: 
- Clearing browser data will delete everything
- Data is NOT backed up to cloud
- Each browser stores data separately

## Troubleshooting

### "Invalid credentials" error
- Make sure you typed: `admin` and `1234` exactly
- Check for extra spaces

### Tasks disappeared
- Did you clear browser data/cookies?
- Try a different browser or device
- Check if localStorage is enabled

### Theme not saving
- Make sure cookies/storage is enabled
- Refresh the page after toggling theme

### Can't access dashboard
- Make sure you logged in first
- Try logging out and in again
- Clear browser cache and reload
